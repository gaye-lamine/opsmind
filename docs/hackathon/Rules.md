# Google Cloud Rapid Agent Hackathon - Official Rules

## ⚖️ Key Legal Points
- **Eligibility**: Open to individuals and teams (max 4 people).
- **Binding Agreement**: Entry constitutes acceptance of these rules.
- **Intellectual Property**: You retain ownership, but must use an **OSI-approved Open Source license** (MIT, Apache, etc.).

## 🛠 Project Requirements
- **Must Use**: Google Cloud AI tools (Gemini) + at least one Partner MCP server.
- **Prohibited**: Using competing AI tools (OpenAI, Anthropic, etc.) is strictly forbidden.
- **New Work**: The project must be created during the contest period (starting May 5, 2026).
- **Platforms**: Must run on Web, Android, or iOS.

## 📦 Submission Essentials
- **Public Repo**: Must be public and include a detectable license file in the 'About' section.
- **Demo Video**: 
    - Max **3 minutes** (only first 3 minutes are judged).
    - Must show the project functioning.
    - Must be in English or have English subtitles.
- **Text Description**: Summary of features, tech stack, and findings/learnings.

## 🏁 Judging Process
- **Stage 1 (Viability)**: Automated pass/fail check (Is it functional? Is it complete?).
- **Stage 2 (Expert Panel)**: 
    - Technological Implementation (25%)
    - Design & UX (25%)
    - Potential Impact (25%)
    - Quality of the Idea (25%)
