# Google Cloud Rapid Agent Hackathon - Overview

## 🎯 The Mission
Build a functional agent that **takes action** (not just a chatbot) using Gemini's reasoning and Partner MCP servers.

## 🏆 Prize System (The "Partner Bucket")
- **Total Prizes**: $60,000
- **Partners**: Arize, Elastic, Fivetran, GitLab, MongoDB, Dynatrace.
- **OpsMind Positioning**: We are integrating **MongoDB** (Memory/Context) and **GitLab** (Action/Remediation). This gives us a competitive edge in two specific tracks.

## ⚖️ Judging Criteria
1. **Technological Implementation**: Quality of software development and integration with Google Cloud & Partners.
2. **Design**: User experience and visual excellence (Aesthetics are key!).
3. **Potential Impact**: Impact on target communities/industries.
4. **Quality of the Idea**: Creativity and uniqueness.

## 📦 Submission Requirements
- **URL to Hosted Project**: Need to plan deployment.
- **Public Repository**: Must include a clear Open Source License.
- **Demo Video**: ~3 minutes (Show the agent reasoning and executing actions).
- **Deadline**: June 11, 2026 @ 10:00pm GMT+1.

## 🚀 OpsMind Strategy
- **Beyond Chat**: Show the "Autonomous Monitoring → Analysis → GitLab Remediation" loop.
- **Multi-Step Mission**: Demonstrate the 8-step pipeline where the agent plans its investigation.
- **Partner Power**: Deep integration with MongoDB Atlas Vector Search and GitLab Duo MCP.
